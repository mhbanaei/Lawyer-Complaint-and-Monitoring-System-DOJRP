# 🏛️ ربات شکایات و دادگاه — ParadiseRP

ربات دیسکورد مدیریت شکایت، دادخواست و دادگاه برای سرور ParadiseRP — فارسی، با تاریخ شمسی.

---

## 📋 امکانات

### ثبت شکایت (`/shekayat`) — نقش شهروند
فرم رسمی «بسمه‌تعالی — فرم ثبت شکایت / دادخواست» در ۵ مرحله:
1. **اطلاعات شاکی:** نام، نام خانوادگی، نام پدر، شناسه/کد ملی، شماره تماس
2. **اقامت و مشتکی‌عنه:** شغل/سمت، محل اقامت (شهر، استان، آدرس کامل، کدپستی)، نام/نام‌خانوادگی/نام‌پدرِ مشتکی‌عنه
3. **ادامهٔ مشتکی‌عنه و موضوع:** شماره تماس، شغل، نوع ارتباط با شاکی، محل اقامت/فعالیت، موضوع شکایت
4. **وقوع و شرح:** تاریخ وقوع (مثل ۱۴۰۵/۰۶/۲۸)، محل وقوع، زمان و نشانی، دلایل و شواهد، شرح کامل شکایت
5. **خواسته:** خواسته / درخواست شاکی

سپس:
- **انتخاب وکیل از منو** (نام و نام‌خانوادگی + تعداد پرونده‌های قبول‌شده) یا «بدون وکیل» — بدون تایپ دستی
- **پیش‌نمایش کامل** + دکمهٔ «تأیید و ارسال» (صحت اطلاعات)
- شمارهٔ ثبت خودکار (ترتیبی) و تاریخ ثبت خودکار به شمسی
- انتشار پرونده در کانال شکایات + **پیام خصوصی به شاکی:** «درخواست شما ثبت شد و تا تعیین وقت دادگاه از طرف قاضی شکیبا باشید…»
- **کول‌داون:** هر کاربر فقط **یک پروندهٔ باز** در هر لحظه دارد؛ تا صدور رأی نهایی امکان ثبت جدید نیست.

### پنل قاضی (دو دکمه زیر پرونده — فقط نقش قاضی)
**🏛️ تنظیم قرار دادگاه**
1. انتخاب نوع جلسه: **خصوصی / عمومی**
2. انتخاب روز از منوی ۷ روز آینده (با تاریخ شمسی و روز هفته)
3. انتخاب ساعت از منو (بازهٔ قابل تنظیم در .env)
4. انتشار **متن از پیش آماده‌شدهٔ** اطلاعیه (متن متفاوت برای جلسهٔ خصوصی/عمومی) در کانال جلسات + منشن شاکی
5. به‌روزرسانی خودکار Embed پرونده با وقت جلسه

**⚖️ اخذ رأی پایانی**
1. انتخاب نتیجه: **به نفع شاکی / به نفع مشتکی‌عنه**
2. ثبت متن رأی در فرم
3. پیام پرونده **به‌صورت ویرایش‌شده** به قالب تمیز «رأی نهایی» تبدیل می‌شود (رأی قاضی زیر متن شکایت)
4. پرونده بسته می‌شود؛ دکمه‌ها حذف، آمار برد/باخت وکیل ثبت، کول‌داون شاکی آزاد، پیام خصوصی نتیجه به شاکی

### پنل وکیل (سه دکمه زیر پرونده)
- **📂 مطالعهٔ پرونده:** فقط پس از تعیین وقت دادگاه فعال می‌شود؛ **فقط وکیلِ پذیرنده** (به‌علاوهٔ قاضی و معاونت) می‌تواند متن کامل را ببیند.
- **🧑‍⚖️ پذیرش وکالت شاکی / 🛡️ پذیرش وکالت مشتکی‌عنه:** فقط پس از تعیین وقت دادگاه؛ **تنها یک وکیل در هر سمت** (اولین وکیلِ پذیرنده قفل می‌شود).

### مدیریت وکلا — نقش معاونت قضایی
| کامند | توضیح |
|---|---|
| `/addvakil کاربر مدت_روز شناسه_بازی نام نام_خانوادگی` | افزودن وکیل؛ بازیکن از `players.json` سرور با شناسهٔ درون‌بازی یافت و نام درون‌بازی او ثبت می‌شود. دورهٔ وکالت مثلاً ۳۰ روزه از همین لحظه روزشماری می‌شود. |
| `/removevakil نام نام_خانوادگی` | حذف وکیل به همراه نمایش آمار نهایی او |
| `/list` | **لیدربورد وکلا** بر اساس زمان آنلاین: وضعیت 🟢/⚫ آنلاین (مقایسه با players.json)، زمان تجمیعی آنلاین، روزشمار معکوس دورهٔ وکالت، تعداد پرونده‌های قبول‌شده و برد/باخت |

- زمان آنلاین هر وکیل به‌صورت خودکار (هر ۵ دقیقه) از سرور بازیکنان پایش و تجمیع می‌شود.
- پایان دوره به‌صورت خودکار علامت می‌خورد (حذف نهایی فقط با `/removevakil`).
- برد/باخت از نتیجهٔ رأی نهایی محاسبه می‌شود: اگر پرونده به نفع سمتِ وکیل تمام شود = برد.

## ⚙️ راه‌اندازی

### ۱) ساخت ربات در دیسکورد
1. در [Discord Developer Portal](https://discord.com/developers/applications) یک Application بسازید و بخش Bot → Token را کپی کنید.
2. زیر Bot، این **Privileged Gateway Intents** را روشن کنید:
   - ✅ SERVER MEMBERS INTENT
3. بخش OAuth2 → Client ID را کپی کنید.
4. ربات را با آدرس زیر به سرور اضافه کنید (Scopes: `bot` + `applications.commands`):
   ```
   https://discord.com/api/oauth2/authorize?client_id=CLIENT_ID&permissions=277025508352&scope=bot+applications.commands
   ```

### ۲) پیکربندی
```bash
cp .env.example .env
# سپس مقادیر را در .env کامل کنید:
# BOT_TOKEN , CLIENT_ID , ROLE_CITIZEN , ROLE_JUDGE , ROLE_DEPUTY ,
# CHANNEL_COMPLAINTS , CHANNEL_SESSIONS , PLAYERS_URL
```
(برای گرفتن ID نقش/کانال: تنظیمات دیسکورد → پیشرفته → حالت توسعه‌دهنده را روشن کنید و راست‌کلیک → Copy ID)

### ۳) اجرا

**ویندوز (پیشنهادی):** روی فایل **`start.bat`** دابل‌کلیک کنید — خودش نصب وابستگی، ثبت کامندها و اجرای ربات را انجام می‌دهد، پنجرهٔ بزرگ با لاگ زندهٔ فارسی و ضربان هر ۵ دقیقه نشان می‌دهد و اگر ربات کرش کند تا ۵ ثانیه بعد دوباره بالا می‌آید.

یا دستی:
```bash
npm install
npm run deploy   # ثبت کامندهای اسلش (فقط یک بار پس از تغییر کامندها)
npm start        # اجرای ربات
```

### تست‌ها
```bash
npm test   # تست مبدل تاریخ شمسی و ابزارهای فارسی
```

### 🌐 فرم وب و HTTPS روی VPS

فرم رسمی شکایت در مسیر **`/Shekayat`** سرو می‌شود و پیش‌فرض `WEB_PORT=80` است؛ یعنی آدرس بدون پورت:
- لوکال: `http://127.0.0.1/Shekayat`
- روی VPS: `http://YOUR_DOMAIN/Shekayat` (پورت‌های ۸۰ و ۴۴۳ را در فایروال VPS باز کنید)

**HTTPS با دامنه — دو راه:**

1. **SSL خودکار (پیشنهادی — بدون کار دستی):** فقط در `.env`:
   ```
   SSL_DOMAIN=lspd.ir
   WEB_PUBLIC_URL=https://lspd.ir
   ```
   همین! با دابل‌کلیک `start.bat`، ربات **خودش گواهی Let's Encrypt را می‌گیرد** (و هر بار نزدیک انقضا خودکار تمدید می‌کند)، HTTPS را روی ۴۴۳ بالا می‌آورد و HTTP را به HTTPS ریدایرکت می‌کند. گواهی در پوشهٔ `ssl/` ذخیره می‌شود.
   پیش‌نیازها:
   - رکورد **A** دامنه (`lspd.ir`) به IP سرور اشاره کند
   - پورت‌های **۸۰ و ۴۴۳** در فایروال VPS باز باشند (۸۰ برای تأیید Let's Encrypt ضروری است)
   - در ویندوز ربات با **Administrator** اجرا شود (برای گوش‌دادن به ۸۰/۴۴۳)
   - `start.bat` خودش با Administrator اجرایش می‌کند؛ پیام‌های `[SSL]` در کنسول وضعیت را نشان می‌دهد

2. **Cloudflare (بدون گواهی روی سرور):** دامنه را از Cloudflare عبور دهید (پروکسی نارنجی). HTTPS در لبهٔ Cloudflare برقرار می‌شود و ربات همان HTTP روی پورت ۸۰ می‌ماند. مقادیر `SSL_DOMAIN` را خالی بگذارید و فقط `WEB_PUBLIC_URL=https://YOUR_DOMAIN` را تنظیم کنید.

3. **گواهی دستی:** با [win-acme](https://www.win-acme.com/) گواهی بگیرید و در `.env`:
   ```
   SSL_CERT_PATH=C:\certs\cert.pem
   SSL_KEY_PATH=C:\certs\key.pem
   ```

پس از هر تغییر `.env`، ربات را با بستن پنجرهٔ `start.bat` و اجرای دوباره ری‌استارت کنید.

data/                       cases.json , vakils.json , state.json (خودکار ساخته می‌شود)

## ⚠️ نکات مهم
- **گواهی HTTPS سرور بازیکنان منقضی است** — ربات برای همین آدرس اعتبارسنجی گواهی را نادیده می‌گیرد (فقط برای `x.paradiserp.ir`). توصیه می‌شود گواهی سرور FiveM تمدید شود تا اتصال امن کامل شود.
- برای `/addvakil` باید بازیکن **آنلاین** باشد تا در `players.json` دیده شود.
- ربات باید نقش خودش **بالای نقش‌های قاضی/معاونت/شهروند** در سلسله‌مراتب سرور قرار بگیرد.
- داده‌ها در پوشهٔ `data/` به‌صورت JSON ذخیره می‌شوند؛ از آن نسخهٔ پشتیبان بگیرید.
